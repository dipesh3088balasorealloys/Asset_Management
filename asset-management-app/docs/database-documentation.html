Database Tables (17)
Core Business Tables 7 tables
TableRowsPurpose & Use CaseKey Columns
assets295 Master table for all IT assets (laptops, desktops, etc.). Tracks inventory, location, vendor, pricing, warranty. Supports soft delete via is_deleted. id, category, name, serial_no, quantity, assigned, available, vendor, location_id, price
assignments281 Tracks which employee has been assigned assets/licenses. Links to departments and locations. Each assignment can have multiple assets via assignment_assets. id, emp_name, emp_id, department_id, emp_email, location_id, assign_date, is_active
assignment_assets286 Junction/bridge table linking assignments to assets (many-to-many). One employee can have multiple assets, one asset belongs to one active assignment. assignment_id → assignments.id, asset_id → assets.id, quantity
assignment_licenses0 Junction table linking assignments to software licenses (many-to-many). Tracks which licenses are assigned to which employee. assignment_id → assignments.id, license_id → licenses.id, quantity
licenses0 Manages software license inventory. Tracks license keys, vendor, validity period, usage count. Supports expiry alerts. id, name, quantity, used, available, license_key, start_date, end_date, vendor
services0 IT services & subscriptions (SaaS, Cloud, Maintenance, etc.). Tracks cost, billing cycle, contract period for cost analysis. id, type (enum), name, provider, cost, status, billing_cycle, start_date, end_date
ewaste1 E-waste disposal records. Tracks disposed assets, billing, vendor, cost, and reason. Linked to photos via ewaste_photos. id, title, billing_number, asset_names (JSON), disposal_date, disposed_to, disposal_cost
Reference & Lookup Tables 3 tables
TableRowsPurpose & Use CaseKey Columns
locations4 Plant/office locations. Each asset and assignment is linked to a location. Used for location-based filtering across the app. id, name, code (unique), is_active
departments64 Department master list. Used in assignments for categorization. Auto-created during data import. id, name (unique)
user_locations1 Junction table restricting which locations a user (manager/viewer) can access. Admins bypass this restriction. user_id → users.id, location_id → locations.id
System & Audit Tables 4 tables
TableRowsPurpose & Use CaseKey Columns
users5 Application users with hashed passwords. Three roles: admin, manager, viewer. Tracks last login time. id, employee_id, email, password_hash, full_name, role (enum), is_active
audit_log7 Immutable audit trail of all system actions. Logs CREATE, UPDATE, DELETE, ASSIGN, UNASSIGN, IMPORT, LOGIN with old/new JSON values. id, user_id, action (enum), entity_type, entity_id, old_values (JSON), new_values (JSON)
email_log0 Tracks all outbound emails sent by the system (assignment notifications, alerts). Logs delivery status and errors. id, to_email, subject, template, status, error
ewaste_photos0 Photo attachments for e-waste disposal records. Supports multiple photos per record with type classification. id, ewaste_id → ewaste.id, file_path, photo_type, original_name
Backup & Recovery Tables 3 tables
TableRowsPurpose & Use CaseKey Columns
db_backups1 Database backup schedule tracking. Records backup type, schedule, status, size, and responsible person. id, database_name, db_engine, backup_type, backup_schedule, last_backup_status, backup_size_gb
server_backups1 Server backup tracking. Monitors server-level backup schedules, storage paths, and backup health. id, server_name, server_ip, backup_type, backup_schedule, last_backup_status
employee_backups2 Employee data backup records (email, OneDrive, desktop/laptop). Tracks which backups are completed per employee. id, email_id, user_name, email_backup, onedrive_backup, desktop_laptop_backup, disk_name
